# BathOS

BathOS is a modular platform for organizing everyday life.

- **Budget**: Manage shared expenses and household finances
- **Drawers**: Plan shelving and drawer layouts
- **Garage**: Track vehicle maintenance and service history
- **Snake**: Record snake growth and weight
- **Tasks**: Organize personal tasks and plans
- **Wardrobe**: Catalog clothing and related details

[Open BathOS](https://os.bath.garden)
